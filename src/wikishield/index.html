Setup required
Windows (Permanent)
  1. Press Win + R, type sysdm.cpl, and press Enter
  2. Go to the "Advanced" tab and click on "Environment Variables"
  3. Create a new variable under "System variables"
  4. Set the name to OLLAMA_HOST and the value to http://127.0.0.11434
    • NOTE: You can change the port (11434) if that port is already in use, but make sure to update the "Server URL" setting in WikiShield accordingly
  5. Click "OK" to save the variable
  6. Create another variable under "System variables"
  7. Set the name to OLLAMA_ORIGINS and the value to https://*.wikipedia.org
  8. Click "OK" to save the variable, you can now close the Environment Variables and System Properties windows
  9. Restart Ollama
Windows (Temporary) 
$env:OLLAMA_HOST="http://127.0.0.11434"
$env:OLLAMA_ORIGINS="https://*.wikipedia.org"
ollama serve
macOS / Linux Add the following to ~/.bashrc or ~/.zshrc: 
export OLLAMA_HOST="http://127.0.0.11434"
export OLLAMA_ORIGINS="https://*.wikipedia.org"
Then run: 
source ~/.bashrc && ollama serve
