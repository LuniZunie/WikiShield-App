2.0.0

Version 2.0.0

26 May 2026, 03:00 UTC

WikiShield App

WikiShield is now available as a standalone desktop application!

  • Available for Windows, macOS, and Linux
  • Built-in browser and translation
  • Desktop notifications
  • Supports OAUTH2 login for multiple accounts and servers

Abuse Log

A new feed has been added for reviewing the abuse log.

  • See what filters were hit and what actions were taken
  • If a revision can be connected to a filter hit, it will be revertable directly from the abuse log

UI Enhancements

Multiple improvements to the user interface.

  • Added an official logo
  • General overall and major imporvement on UI clutter
  • Improved consistency of styling throughout the interface
  • Warnings can now be previewed by clicking the help button next to them
  • Added a button to remove individual items from a queue
  • Added a refresh button for user contributions and page history
  • Wikitext is now handled in edit summaries and similar scenarios
  • Added an indicator in the queue for if an edit has alreadt been viewed

Global Support

Added support for global blocks, global locks, and global permission.

  • Added a new action for requesting global blocks and global locks
  • Global rollback is now detected and allows for usage of the app

Zen Mode

Improved Zen Mode background audio.

  • Music has been replaced with procedurally generated ambient sounds
  • Nature sounds can now be heard in Zen Mode

Control Scripts

Added multiple new features to control scripts.

  • Keyboard shortcuts now support modifier keys (e.g. Ctrl+Shift+R)
  • More complex conditions have been added
  • Added a new "if not" function which checks if the condition is not met

Templates

Improvements to warning and welcome templates

  • Added no edit summary, harrassment, and english varient warnings
  • Added vandalism fighter welcome template
  • Mutliple warning templates have been fixed

Accessibility Features

Added multiple accessibility features.

  • Added more colorings for ORES scores to accommodate color blindness
  • Added a dyslexia-friendly font option
  • Added an option for reduced motion

ORES Improvements

More ORES models are now supported.

  • "Damaging" and "Good Faith" models are now both supported
  • Models can be weighted differently in the settings

Profanity Filter Improvements

The profanity filter has been improved to reduce false positives.

  • Added more words to the filter
  • Improved the accuracy of the filter to reduce false positives
  • Profanity scores are now visible in the user creation feed

Settings

Updated app settings

  • Duration inputs now support actual time durations
  • Removed cloud saving option, cloud saving is now always enabled
  • Added a new toggle for talk page messages being sent when thanking new anonymous users

API Improvements

Improved API handling and performance.

  • Reduced the number of API requests needed for various actions
  • Improved error handling for API requests
  • API speed has increased

Miscellaneous

  • Edits cleared in one queue are now cleared in all queues
  • Added a confirmation dialog when reverting, reporting, or warning whitelisted users
  • Added credits to script
  • Added easter eggs
  • Improved AI functionality
  • Removed unneeded sounds
  • Numerous bug fixes and performance improvements
1.2.0

Version 1.2.0

14 December 2025, 22:30 UTC

Warning System Reworked

The warning system has been completely overhauled for better usability and functionality.

  • All warning templates are now available for reverting or warning
  • Reverts can now optionally include a warning
  • Warning menu has been reworked for better organization and usability
  • Added uw-harassment, uw-nor

Wikipedia Popups

Added a new setting to control how Wikipedia links are opened.

  • Links in the top bar now have a menu for what to do when clicked
  • When enabled, Wikipedia links will open in a new window.
  • When disabled, Wikipedia links will open in a new tab.
  • Note: This feature is not supported by Opera or Safari browsers.

Bug Fixes

  • Fixed issue where audio volumes would not work
  • Fixed bug where audio volumes would not save
  • Fixed an error when whitelisting or highlighting directly from the settings menu
  • Fixed a bug where some actions would execute when they weren't supposed to
  • Fixed an error when middle clicking some buttons in the UI

Miscellaneous

  • Improved the profanity filter to catch more sockpuppets
  • Reduced strain on Wikimedia servers by optimizing API requests
  • Added external loading to reduce script size

Version 1.1.2

Watchlist Enhancements

Pages can now be watched or unwatched directly from the queue.

  • In the page menu, Watch page and Unwatch page options have been added
  • When a page is unwatched, all edits in the watchlist queue for that page are removed
  • Watchlist statistics are now tracked

User Creations

User creation profanity filter improvements.

  • A "note on file" has been added to certain filter hits
  • Slight improvements to filter accuracy

Queue Navigation Improvements

Multiple bugs have been fixed.

  • Pending changes are no longer removed when navigating between edits
  • When clicking on user contributions or the page history, the current edit is replaced rather than removed

Security Fixes

Multiple security fixes.

  • Fixed an issue where a user could log out while still maintaining access to WikiShield features
  • Fixed an issue where a user who lost rollback rights while running the script could still access WikiShield features

Miscellaneous

Other changes and improvements.

  • Fixed a bug where usernames in accepted and rejected pending changes were occasionally not built correctly
  • Fixed an issue with the display for session time in statistics

New Queues!

Introducing: pending changes, user creation, and watchlist queues.

  • Queues can be toggled and rearranged in the new "Queue" appearance settings page
  • Badge icons indicate number of items in each queue
  • Note: The pending changes tab requires the review user right

Notices & Alerts

Multiple improvements to notices and alerts

  • All notifications have an updated style to align with Wikipedia
  • Notices and alerts have been separated into distinct panels
  • Notifications read on WikiShield are now read on Wikipedia
  • Added the ability to mark individual notifications as read or unread
  • Tab title now includes the number of unread notifications

New Audio

Sounds have been updated and music (?!) has been added.

  • Sound quality has been improved
  • Music has now been added to Zen Mode for some reason...

Username Mentions

Improved handling of username mentions

  • A new option has been added for fuzzy matching usernames
    • Available in the "Gadgets" settings page
    • When enabled, WikiShield will match usernames that are similar to your own
  • Edit summaries now include username mentions
  • In the user creation tab, usernames similar to yours are highlighted
  • Added an indicator to tab icons when there are edits mentioning your username

User Blocks

More functionality related to user blocks

  • Users who are currently blocked now have their name struck through
  • Improved block detection, you can now see all the blocks by hovering over the block indicator

AI Analysis

AI analysis has been improved and expanded

  • Fine tuning has been done to improve accuracy
  • AI analysis is now available in the user creation, pending changes, and watchlist queues

Queue Items

Various improvements to queue items

  • Added ORES score to user contributions and page history items
  • Timestamps have been added to queue items
  • Cutoff text can now be hovered to see the full text
  • Items in the queue should no longer be repeated
  • Fixed navigation bugs

Statistics

Statistics have been completely revamped

  • More detailed statistics have been added
  • Fixed various bugs with statistics calculations
  • (Yes, this does mean your stats have been reset)

UI Improvements

Various improvements to the user interface

  • New welcome screen design
  • Multiple new settings options have been added
  • Styling has been improved throughout the interface
  • Various bug fixes and performance improvements

Miscellaneous

Other changes and improvements

  • RfPP now has "Generic" and "Disruptive Edits" subcategories
  • Not English warning has been moved to the "Revert" menu
  • Removed personal edit count from the bottom tool bar
  • "Time ago" now updates dynamically without needing to refresh
  • Buttons that cannot be used for the current queue item are now hidden
  • Fixed bug related to Zen Mode on startup
  • Fixed bug where ORES scores would not load properly
  • Changed multiple edit summaries to be more standardized
